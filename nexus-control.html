NEXUS CONTROL CENTER

Builder · Updates · Downloads · Account shortcuts

Build & Download

Package the current source into a ZIP. Local data, Git history and environment secrets are excluded.

Update Panel

Fast-forward the current Git branch. Updates stop if there are uncommitted changes.

Delete Source

Creates a backup ZIP first, then removes this source checkout. This does not uninstall a separately running panel process.

Open Nexus Panel

Go to the running hosting panel to manage servers and existing customer accounts.

Create Owner

Owner creation is available during the panel's first-run setup only.

Admin & User Accounts

Customer/User accounts are managed inside the authenticated panel. A separate Admin role is not yet implemented in this branch.

Ready. This Control Center binds to localhost only.
